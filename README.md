# Python Dynamic Island (iOS Clone for Windows)

这是一个基于 Python 和 PySide6 开发的高度仿真 iOS 灵动岛项目，专为 Windows 系统设计。它不仅具备 iOS 灵动岛的经典交互与视觉美学，还集成了丰富的系统监控与控制功能。

---

## 🚀 核心功能

- 🖱️ **智能鼠标穿透**：默认状态下完全穿透，不干扰桌面操作；展开后自动恢复交互。
- 📱 **多态吸附与自适应**：
  - 支持吸附至屏幕 **上方、左侧、右侧**。
  - **自动形态切换**：顶部吸附为横向模式，侧边吸附自动转为纵向模式。
- 🎨 **多巴胺视觉系统 (Dopamine UI)**：
  - **毛玻璃效果**：集成 Windows Acrylic/Fluent 模糊效果（半径 >20px）。
  - **极致圆角**：32px 超大圆角设计，完美还原 iOS 17+ 曲线美学。
  - **多巴胺配色**：主色 #FF6B6B (珊瑚红)、辅色 #4ECDC4 (蒂芙尼蓝)、点缀色 #FFE66D (明黄)。
- 🎵 **音乐媒体控制 (SMTC)**：
  - 自动识别主流播放器（Spotify, 网易云等）的曲目信息。
  - **极简 UI**：移除了占位图标，歌曲信息（歌名/歌手）全局居中显示，视觉更纯净。
  - **Apple Music 风格**：控制按钮（上一曲/播放/下一曲）采用 Apple Music 经典符号。
  - **动态动效**：播放时灵动岛自动扩展并显示 **MusicVisualizer** 实时频谱动画。
  - **兼容性增强**：支持自动发现活跃媒体会话，并针对部分播放器的注册延迟做了容错与重试。
- 🔴 **全能录屏系统**：
  - 一键捕获屏幕，视频自动以 MP4 格式保存至 `video/` 目录。
  - **iOS 风格按钮**：重构录屏按钮为半透明玻璃质感，配合“开始录制/停止录制”专业文案。
  - **录制监控模式**：收起后显示呼吸感红点及实时计时器。
- 🔗 **剪贴板与全局热键**：
  - 实时监控链接复制，灵动岛即时提醒。
  - **Alt + O** 全局热键快速打开最后一次复制的链接。
  - **打开反馈提示**：通过 Alt + O 成功打开链接后，收起状态会以与网络/蓝牙一致的样式提示“已打开复制链接”。
- 🌐 **双重通知机制**：
  - 监控 WiFi 与蓝牙设备连接状态。
  - **iOS 状态图标**：采用信号强度（📶）与蓝牙起源符（ᛒ）作为状态图标。
  - 收起/展开状态下均有视觉一致的居中通知提醒。
- 🔋 **系统状态监控**：
  - 实时显示时间（中文日期/星期）、电池百分比、充电状态。
  - **Segoe UI Variable**：关键文本（日期、通知、录屏）统一采用最新系统字体，粗体白色。
  - **渐变滑块**：音量与亮度滑块采用“蓝-粉-绿”三色梦幻渐变填充。
  - 直接调节系统音量与屏幕亮度。
- 🌍 **国际化 (i18n)**：支持中文 (zh) 与英文 (en) 切换。

## 🛠️ 安装与运行

### 1. 环境要求
- Windows 10/11
- Python 3.8+

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 运行项目
```bash
python dynamic_island.py
```

---

## 📦 核心依赖库
- `PySide6`: 现代 GUI 框架与动画引擎。
- `psutil`: 获取系统、网络与电池状态。
- `winsdk`: 获取 Windows 系统媒体播放信息 (SMTC) 及蓝牙枚举。
- `pycaw` & `screen-brightness-control`: 硬件控制。
- `opencv-python` & `mss` & `numpy`: 高性能录屏实现。
- `pyperclip` & `keyboard`: 剪贴板与全局热键。
